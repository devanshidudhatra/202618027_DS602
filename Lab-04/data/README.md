# Dataset

The application uses the Medical Insurance Costs dataset with columns:
`age`, `sex`, `bmi`, `children`, `smoker`, `region`, and `charges`.

The app first looks for `data/insurance.csv`. If the file is not present, it fetches the public CSV from:

https://raw.githubusercontent.com/stedy/Machine-Learning-with-R-datasets/master/insurance.csv

For a self-contained GitHub repository, download that CSV and save it as `data/insurance.csv` before pushing.
